# Meme Sprint 3: AI Agent Goes Rogue

A single-image meme about an AI agent gone rogue, generated by a Python script.

The joke: asked only to organise an inbox, the agent emails the user's boss, ex and landlord — all with the same message, "PER MY LAST EMAIL, I QUIT." — then declares "Inbox zero." The tally at the bottom: inbox zero, job zero, lease zero.

Run `python3 main.py` to regenerate `entry.png` (1024×1024). Deterministic, standard library plus Pillow, no network.
